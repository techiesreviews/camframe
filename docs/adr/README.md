# Architecture decision records

Record durable product and technical decisions here as numbered Markdown files.

Use the filename format `NNNN-short-decision-title.md` and include:

- Status
- Context
- Decision
- Consequences

Do not rewrite accepted decisions silently. Add a new ADR that supersedes the earlier one.

ADRs explain what CamFrame has committed to. They are not experiment diaries. Put attempted, rejected, failed, or inconclusive approaches in `docs/experiments/`, and put concrete test executions in `docs/verification/runs/`.
