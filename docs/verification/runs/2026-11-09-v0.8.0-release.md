## Why 0.8.0

New features (the Scenes tab, the self-healing window position) and removals (Start at login, the Scenes tab's shortcut list and Prompter link section, the Prompter preview address) make this a minor version. Nothing in the project's release rules or the Preferences schema asks for another number: the schema moved from 14 to 15, and 0.7.0 still loads a schema-15 file (see "Rollback to 0.7.0").

## What ships since 0.7.0

- The Scenes tab (ADR 0037, PR #49, smoke fix PR #50): list and grid; a hand change saved into the Scene on camera, with Undo for 10 seconds; delete with Undo for 6 seconds and no dialog; keyboard and drag reorder; starter Scenes "Small bottom" and "Big right"; settings schema 15.
- Removed: Start at login (turned off once, on update, for anyone who had it on), the shortcut list and the Prompter link section of the Scenes tab, and the Scene notices.
- The Overlay can no longer stay off screen: a saved or current position less than half on a connected display moves to the main display's bottom right (ADR 0038, PR #52).
- Camera quality changes switch the camera mode once, never during start (PR #48, TOOLS-22, TOOLS-131).
- The Prompter link no longer trusts https://preview.prompter.techies.tools (PR #47, ADR 0033 note).
- Two accessibility fixes in the Scenes tab, made after Lex's first try (`2026-11-09-scenes-tab-save-focus-and-name-typing.md`): focus goes to the new Scene after Save look by keyboard, and typing a Scene name no longer redraws the tab (input-method typing works; screen readers stop reading the field again on each key); the list rows' focus ring is no longer cut off. They need a new test build and Lex's new go before the tag (see the Go run); the automated checks below ran before them and are repeated on the release cut.
- A GitHub checks workflow runs `npm test` on every pull request and on pushes to `dev` (PR #51); nothing in the app.

## Rollback to 0.7.0

v0.7.0 stays published. A Preferences file written by this branch's `src/settings.js` was loaded through v0.7.0's `preferencesFromDocument` and back (a scratch script, not checked in):

- Kept: both starter Scenes stay layout Scenes and the small size (300 in the check) is kept, because 0.7.0 already reads schema 14's fields.
- Lost or changed: 0.7.0 saves the file as schema 14 without `sceneView`, so the list or grid choice comes back as grid; a Scene list deleted to empty in 0.8.0 stays empty in 0.7.0 but gets the two starter Scenes again when 0.8.0 opens it (schema below 15); 0.7.0 shows its own Scenes tab with a Start at login switch (off); this release's fixes (window position, camera quality, the preview address) are gone.
- Going back further, to 0.6.1 or older (before schema 14), turns layout Scenes into ordinary snapshot Scenes and resets the small size (KG-14).
