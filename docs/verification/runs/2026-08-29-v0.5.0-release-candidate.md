## Regressions and surprises

- Electron Builder 26.15.3 repeatedly failed on Windows with `EPERM` while renaming its locked unpack directory. Pinning 26.15.5 selected the upstream retrying move and produced the inspected packages; ADR 0027 records the durable decision.
- Starting overlapping local packagers against one output directory caused process and filesystem contention. Those outputs are excluded from evidence; see `experiments/2026-08-29-windows-packaging-process-contention.md`.
- A final local `npm ci` resolved the regenerated lock but stalled while writing the workspace dependency tree. Generating the same lock in a clean temporary directory completed in six seconds. CI installation is the authoritative clean-environment result; the interrupted local `node_modules` directory is generated and not release evidence.
- T3 could evaluate the running renderer but could not resize, snapshot, or record it. Playwright's Electron driver now supplies durable Windows screenshots instead.
