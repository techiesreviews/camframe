## Regressions and surprises

The 0.9.0 camera id cannot directly select a native backend device: Chromium hashes ids for its
origin. The first Rust start uses the saved camera label as a fallback; duplicate labels remain
ambiguous. No change is made to 0.9.0's file. Native identity is stable after selection in Rust.
Linux compilation cannot prove native menu or shortcut behavior. `kit ux` lacks a feature list,
and existing `kit shots` covers the Electron app rather than the new GPUI controls.
