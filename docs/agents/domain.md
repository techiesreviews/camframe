# Domain docs

CamFrame uses a single-context documentation layout.

Before exploring or changing the codebase, read:

- `CONTEXT.md` for project terminology and module ownership.
- Relevant records under `docs/adr/` for durable decisions.

Use the terms defined in `CONTEXT.md` in issues, tests, proposals, and code review. If work conflicts with an accepted ADR, surface the conflict explicitly rather than silently overriding it.
